# Quality Policy (ISO 9001 / ISO 25010)

## Misión de Calidad
Asegurar que el sistema de Identidad y Accesos (IAM) provea un servicio de alta disponibilidad (99.9%), mantenga la integridad absoluta de los datos de sesión de los usuarios y cumpla con las normativas internacionales de protección de datos (LFPDPPP).

## Estándares de Código (ISO 25010)
- **Mantenibilidad**: Se aplican principios SOLID y arquitectura MVC modular.
- **Eficiencia**: Las consultas a base de datos están optimizadas utilizando Pool de conexiones (MySQL2).
- **Usabilidad**: Frontend desarrollado con React 18, garantizando interactividad fluida (GSAP) y responsividad.
- **Fiabilidad**: Manejo global de excepciones en Node.js y validaciones estrictas en la ingesta de datos.
